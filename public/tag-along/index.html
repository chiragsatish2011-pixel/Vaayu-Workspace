Tag Along

Learn to build a webpage, one tag and one style at a time.

Why this page exists

Videos move fast and jump around — this page doesn't. The goal here is to mix practical, hands-on coding with just enough theory to understand why something works, and to explain the tricky parts in plain, simple language instead of technical jargon.

Part 1 · HTML Tags

These seven groups cover every tag you need for now. Go through them in order — each one builds on the last. Copy the code into a file, save it as .html, and open it in your browser to see it work.

Part 2 · CSS Styling

CSS is a huge subject, so this only covers what's necessary to confidently style the pages you already know how to build. No fancy layouts yet — just color, text, and spacing.

Part 3 · Practice Zone

Three small projects using only what you've already learned. For each one: look at the sample, read the steps, and try building it yourself first. The full code is hidden at the bottom in case you get stuck.
